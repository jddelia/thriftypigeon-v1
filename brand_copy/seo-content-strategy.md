# SEO-Focused Content Strategy

## SEO Philosophy Aligned with Brand

**Goal**: Rank for keywords that people with real money problems are searching for, from complete beginners to action-takers. Focus on helpful, complete answers that serve the search intent fully.

**Approach**: Create genuinely comprehensive content that Google wants to rank, not SEO-optimized fluff. The best SEO is great content that actually helps people.

## Keyword Research Strategy

### Tools and Approach
**Primary Tool**: Ahrefs/SEMrush for data, Google Keyword Planner for validation
**Secondary Tools**: AnswerThePublic for question-based content, Google Trends for timing

**Research Process:**
1. **Start with seed keywords** from each pillar
2. **Identify question-based queries** (how to, what is, why do)
3. **Find long-tail variations** with commercial intent
4. **Map to user journey** (awareness → consideration → action)
5. **Prioritize by difficulty + volume + intent**

### Keyword Difficulty Targeting

**Target Mix (per 10 articles):**
- 3 articles: High volume, medium-high difficulty (build authority)
- 5 articles: Medium volume, low-medium difficulty (steady traffic)
- 2 articles: Low volume, low difficulty (quick wins)

**Difficulty Ranges:**
- High: 40-60 difficulty (competitive but achievable)
- Medium: 20-40 difficulty (sweet spot for growth)
- Low: 10-20 difficulty (easier wins)

### Seasonal Keyword Planning

**January (New Year's Resolutions)**
- Budget planning keywords spike
- Goal-setting content performs well
- "Start [financial habit]" keywords peak

**April (Tax Season)**
- Tax-related side hustle content
- Expense tracking and organization
- "Tax preparation" adjacent keywords

**September (Back to School)**
- Budget reset and planning
- Student financial topics
- "Prepare for [financial goal]" content

**November-December (Holiday Season)**
- Holiday budgeting and saving
- Gift-giving on a budget
- Year-end financial planning

## On-Page SEO Strategy

### Title Tag Optimization

**Formula**: [Target Keyword]: [Benefit/Year] ([Character Limit: 50-60])

**Examples:**
- "How to Build Emergency Fund: Complete 2025 Guide"
- "Best Budgeting Methods: 50/30/20 vs Zero-Based vs Envelope"
- "21 Ways to Save $100 This Month (Real Examples)"

**Best Practices:**
- Primary keyword in first 5 words
- Include year for freshness
- Specific benefit or number
- Under 60 characters

### Meta Description Strategy

**Formula**: [Benefit] with this [content type]. Get [specific value] + [implementation detail]. [Optional CTA/playbook mention].

**Examples:**
- "Build a $1000 emergency fund in 6 months with this proven system. Get step-by-step instructions, real examples, and the exact spreadsheet I used."
- "Compare 3 best budgeting methods with pros, cons, and setup guides. Includes free templates for each method plus complete implementation toolkit."

### Header Structure (H1-H6)

**H1**: Primary keyword + clear benefit
**H2**: Section headers with keyword variations
**H3**: Subsections with long-tail keywords
**H4-H6**: Detailed breakdowns

**Example Structure:**
```
H1: How to Build an Emergency Fund: Complete 2025 Guide
H2: What is an Emergency Fund? (Beginner Basics)
H2: How Much Should You Save in an Emergency Fund?
  H3: Emergency Fund Calculator Method
  H3: Emergency Fund Amount by Income Level
H2: Where to Keep Your Emergency Fund
  H3: Best Emergency Fund Accounts
  H3: Emergency Fund vs Savings Account
H2: How to Build Emergency Fund Fast
  H3: Automatic Emergency Fund Savings
  H3: Side Income for Emergency Fund
```

### Internal Linking Strategy

**Hub and Spoke Model:**
- Pillar pages link to all related content
- Supporting articles link back to pillar
- Related articles cross-link when contextually relevant

**Link Building Priorities:**
1. New articles link to established pillar content
2. Update old articles to link to new related content
3. Create topic clusters with strong internal link structure
4. Use contextual anchor text with keyword variations

## Technical SEO Considerations

### Site Speed Optimization
- Target: <2.5s LCP (Largest Contentful Paint)
- Optimize images (WebP format, compression)
- Minimize JavaScript/CSS
- Use CDN for static assets

### Mobile-First Optimization  
- Responsive design priority
- Mobile-friendly CTA placements
- Readable fonts and spacing
- Touch-friendly button sizes

### Core Web Vitals
- LCP: <2.5s (loading performance)
- FID: <100ms (interactivity)
- CLS: <0.1 (visual stability)

### Schema Markup Implementation

**Article Schema:**
```json
{
  "@type": "Article",
  "headline": "[Article Title]",
  "author": "[Author Name]",
  "datePublished": "[Date]",
  "description": "[Meta Description]",
  "image": "[Featured Image URL]"
}
```

**FAQ Schema** (when applicable):
```json
{
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "[Question]",
    "acceptedAnswer": {
      "@type": "Answer", 
      "text": "[Answer]"
    }
  }]
}
```

## Content Quality Guidelines

### Every Article Must Include:

**Value Requirements:**
- [ ] Completely answers the search query
- [ ] Provides actionable, specific advice
- [ ] Includes real examples with numbers
- [ ] Beginner-friendly explanations
- [ ] Clear next steps for implementation

**SEO Requirements:**
- [ ] Target keyword in title, H1, first paragraph
- [ ] Keyword variations in H2 headers
- [ ] 2-3 internal links to related content
- [ ] 3-5 external links to authoritative sources
- [ ] Meta description with benefit + keyword
- [ ] Alt text on all images

**User Experience:**
- [ ] Scannable formatting (bullets, headers, short paragraphs)
- [ ] Mobile-friendly design
- [ ] Fast loading speed
- [ ] Clear, logical structure
- [ ] Engaging introduction that hooks readers
